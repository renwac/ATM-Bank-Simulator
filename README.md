## 🤝 How to Contribute

❗❗Use CLI❗❗LIKE THIS::::
<img width="637" height="578" alt="Screenshot 2026-03-27 at 16 53 43" src="https://github.com/user-attachments/assets/b3453998-321f-45e8-9032-7e56978e10ee" />

### 1. Make sure you're in the right directory
Before doing anything, confirm you're in the project's root folder:
```bash
pwd
```
You should see something like `/Users/yourname/ATM-Bank-Simulator`. If not, `cd` into it:
```bash
cd path/to/ATM-Bank-Simulator/
```

### 2. ❗❗ Pull the latest changes ❗❗ IMPORTANT❗❗
Always pull before making any edits to avoid conflicts:
```bash
git pull origin main
```

### 3. Make your changes 
Edit whichever files you need to. Once done, double-check what's changed:
```bash
git status
```

### 4. Stage your changes
Add all changed files:
```bash
git add -A OR git add .
```
Or add a specific file:
```bash
git add filename.txt
```

### 5. Commit with a meaningful message
Write a short note describing **what you changed and why** — this helps everyone follow the project history:
```bash
git commit -m "Week 4: added intro section and fixed typo in summary"
```
> ✏️ **Good commit message examples:**
> - `"Week 5: completed analysis for section 2"`
> - `"Fixed broken link in references"`
> - `"Added George's Week 5 notes"`

### 6. Push your changes
```bash
git push origin main
```

---

> ⚠️ **Reminder:** Always `git pull` first before starting work. If you forget and hit a conflict, don't panic — just shout in the group chat.
